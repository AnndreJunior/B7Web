# Herança

Tags herdam propriedades CSS de suas tags pais quando não há um estilo definido para elas. Por exemplo, temos uma div, dentro dela uma tag p e em uma palavra do texto uma tag strong. Se eu definir que meu div vai ter color: #ff0000, então meu parágrafo e meu strong terão os textos com esses valores.

Não são todas as propriedades CSS que possuem essa capacidade de herança, normalmente são propriedades de texto, como color, font-size...

Bordas, por exemplo, são aplicadas apenas nas tags que eu definir, não suas filhas.
