# Unidades de medida absoluta

São valores fixos. Eles não se adaptam a situação da tela e a disposição dos elementos.
Se for definido que a largura de um elemento é 300px, então será 300px independente do que acontecer na tela.

Dentre as unidades de medida absoluta, temos:

- Pixel (px)\*
- Point (pt)
- Polegada (in)
- Centímetros (cm)
- Milímetros (mm)
